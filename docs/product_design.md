# BlindBadge 视障安全提醒胸牌原型

## 用户
视障人士、低视力用户、夜间/陌生环境中需要辅助提醒的人。

## 产品定位
BlindBadge 第一版定位为“视障安全提醒原型”，不是成熟盲人导航设备，也不替代手杖、导盲犬或专业避障设备。

第一版硬件建议基于 ESP32-S3-EYE：使用板载摄像头、按键、加速度计作为感知输入，使用 LCD/串口日志和外接震动马达或蜂鸣器作为提醒输出，通过 Wi-Fi 接入 MiMo，并结合 openvela `ai_agent` 完成安全提醒生成与本地 fallback。

## 场景
胸牌佩戴在胸前，持续监听环境事件。当检测到危险或用户主动询问时，给出短句提醒。

## MVP 功能
1. 主动障碍提醒：模拟 obstacle_near 事件后，胸牌主动提示“前方有障碍，请减速”。
2. 台阶提醒：模拟 step_down 事件后，提示“前方疑似下行台阶，请小心”。
3. 环境问答：用户询问“现在安全吗”，Agent 根据最近事件回答。
4. 一键求助：触发 emergency 事件后，生成求助信息。

## 第一阶段实现方式
QEMU 中先用命令模拟传感器事件，不依赖真实摄像头和超声波。
后续上真机时，把模拟事件替换为真实传感器输入。

## 硬件边界

- ESP32-S3-EYE 板载 OV2640 摄像头可用于前向场景感知和图像采集，但第一版不宣称单目摄像头能提供可靠厘米级距离。
- 板载按键适合优先实现 emergency，一键触发求助流程。
- 板载 QMA7981 加速度计适合做佩戴状态、剧烈运动或跌倒类扩展信号。
- LCD 主要用于开发调试和评委演示，不作为盲人用户主输出。
- 震动马达、蜂鸣器、扬声器、ToF/超声波测距模块不属于 ESP32-S3-EYE 板载能力，需要外接或模拟。

## 分层交付

1. 当前可实现层：ESP32-S3-EYE + openvela + `ai_agent` + MiMo + 按键 emergency + LCD/串口输出 + fallback。
2. 最小外设增强层：外接震动马达或蜂鸣器，形成真实提醒动作。
3. 后续增强层：外接 ToF/超声波做真实距离，再扩展语音播报和视觉识别。
